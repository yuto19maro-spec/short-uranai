# 60秒 誕生日TOP5 ショート動画（1テーマ深掘り型）

伸びている占いショートの構成を再現する縦型動画（1080x1920 / 30fps / ぴったり60.00秒）。
1カット = テロップ1枚 + AI画像1枚 + ナレーション1区切り。

台本の型（書き方のルール・言い回し・チェックリスト）は **`scripts60/TEMPLATE.md`**、参考4本の完全書き起こしは `scripts60/REFERENCE_TOP4.md`。

## 構成（参考チャンネル上位4本の実測）

| 秒 | パート | 例 |
|---|---|---|
| 0〜2.5 | タイトル3行（白／黄／赤） | 実は前世が／王族だった／誕生日TOP5 |
| 〜6.5 | 導入 | この誕生日の人は前世で〜可能性があります |
| 〜10 | コメント誘導 | あなたや身近な人に同じ誕生日がいたらコメントで教えてください |
| 〜13.5 | 保存・フォロー誘導（赤字で煽る） | この動画は2度と表示されないため、今のうちに保存を |
| 〜16.5 | ティーザー | 特に1位は〜／特に最後は要注意！ |
| 〜50 | 第5位〜第2位（各約8秒） | 「第N位」→ 特徴2〜3枚 → 「この誕生日は〇日生まれ」 |
| 〜60 | 第1位 | 特徴 → **「この誕生日はコメント欄」**（固定コメントで答えを出す） |

- 誕生日は「〇日」だけ（月は出さない）→ 1枠で視聴者の約1/31が当てはまる
- 誕生日は各順位の最後に明かす
- 約2秒ごとにカットを切り替える。画像はゆっくりズーム

## 使い方

```bash
./setup60.sh
python3 render60.py scripts60/<name>.json images    # 必要な画像とプロンプト一覧
python3 render60.py scripts60/<name>.json voice     # VOICEVOX でナレーション
python3 render60.py scripts60/<name>.json sheet     # 全カット一覧画像
python3 render60.py scripts60/<name>.json render    # 書き出し
```

画像が無いカットは仮の背景で描画される（`--silent` を付けると VOICEVOX 無しで仮の尺で書き出せる）。

## 台本(JSON)

| キー | 内容 |
|---|---|
| `name` | 画像フォルダ `assets60/<name>/`・出力ファイル名 |
| `youtube_title` / `pinned_comment` | 投稿用のタイトルと固定コメント（1位の誕生日） |
| `voice` | `{"speaker": VOICEVOXの話者ID, "speed": 話速}` |
| `style` | 全画像に共通で付けるプロンプト |
| `images` | `{キー: 画像プロンプト}`。`common/～` は `scripts60/common_images.json` |
| `bgm` / `bgm_volume` | 任意。BGMファイルと音量（既定 0.12） |
| `cuts` | カットの配列（上から順に再生） |

`cuts` の各要素:
- `{"title": ["1行目", "2行目", "3行目"], "say": "読み上げ", "img": "キー"}` … タイトル画面。行の色は既定で白／黄／赤。`"colors": ["r", "y", "w"]` で変えられる
- `{"text": "テロップ（\n で改行）", "img": "キー", "say": "読み上げ（省略時はテロップと同じ）"}`
- `{"text": ..., "cont": true}` … 前のカットと同じ文として続けて読む（文ごとにまとめて合成し、テロップの切り替わり位置で音声を切り分ける）
- テロップ内の `{ }` は黄色、`[ ]` は赤
- カットの長さはナレーションの長さで自動に決まる。話速を自動調整してナレーション合計を約58〜59.6秒にし、残りを各カットの間に均等に足して **ぴったり60.00秒** にする

## 背景に動画を使う（Pixabay）

`"videos": {"キー": "英語の検索ワード"}` を台本に書くと、そのキーのカットは AI画像の代わりに Pixabay の動画が背景になる。

```bash
python3 pixabay60.py test                          # APIキーが動くか確認
python3 pixabay60.py search "misty lake sunrise"   # 候補を見る（縦長を優先）
python3 pixabay60.py fetch scripts60/<name>.json   # "videos" のカットの動画をまとめてダウンロード → assets60/<name>/<キー>.mp4
```

- APIキーは環境変数 `PIXABAY_API_KEY`（Windows: `setx PIXABAY_API_KEY "キー"`）。リポジトリやチャットには書かない
- 動画のファイルがあれば動画、無ければ AI画像、どちらも無ければ仮の背景で描画する
- 横長の動画は中央を縦に切り抜く。短い動画はループする。動画のカットはズームしない
- 取得した動画の出典は `assets60/<name>/<キー>.pixabay.json` に残る（Pixabay Content License: 商用利用可・クレジット不要）
- 全カットを `"videos"` にすれば、実写動画だけの動画も作れる（例: `scripts60/senzo_real.json`。`TEMPLATE.md` の「9. リアル動画版」）
- `"bg_dim": 0.18` のように書くと、動画の背景を少し暗くしてテロップを読みやすくする
