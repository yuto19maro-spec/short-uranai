# 人生の気づき・改善系スピリチュアルショート 台本の型

## 構成（全5項目・約150〜200字/項目以内）
1. **タイトル**：「〇〇な人が△△している/持たない/の特徴/サイン＋5選」
   - 主語は憧れ・自己投影できる人物像（運がいい人／心が軽い人／魂が古い人／本当に優しい人）か、未来の予兆（転機が近づくサイン）
2. **冒頭**：タイトルをそのまま読み上げ → 1文の導入（前提をひっくり返す・共通点の提示）
   - 例「運がいい人は特別なことをしているわけではなく、一日の入り口を丁寧に整えています。」
3. **各項目（1〜5）は3文構成**
   1. 見出し：短い具体的行動・現象（「起きてすぐに窓を開ける。」）
   2. 具体化：日常の情景で言い換える1文
   3. 意味づけ：スピリチュアル/心理的な理由。語尾は「〜と知っているのです」「〜と分かっているのです」「〜サインです」「〜からです」「〜名残です」
4. 締めの別パートは無し。5項目目の意味づけで静かに終える

## トーン・ルール
- です・ます調、静かで断定的。煽らない、否定しない
- 誰でも当てはまりそうな日常の行動・感覚を選ぶ（「自分のことだ」と思わせる）
- 小さな行動 → 大きな意味（空気の入れ替え＝流れ、玄関＝良い知らせ）へ飛躍させる
- 「流れ」「縁」「魂」「入り口」「満ちる」「手放す」などの語彙
- 5項目目は一番共感・余韻が強いもの（経験から知っている／扉が開く直前 など）
- 数字は「1、」形式。漢数字は文中（三つ、十分間）
