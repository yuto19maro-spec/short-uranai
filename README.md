# 誕生日ランキング ショート動画ジェネレーター

参考動画（4タイトル × 誕生日ランキングTOP5、約18.6秒）のフォーマットを再現する縦型動画（1080x1920 / 30fps）レンダラー。

## 準備

```bash
./setup.sh          # フォント取得 + 海の背景動画を生成
```

## 動画を作る

```bash
python3 render.py scripts/template.json -o out/video.mp4
python3 render.py scripts/template.json --preview 7.9     # 7.9秒時点の静止画だけ確認
```

## 台本(JSON)の書き方

| キー | 内容 |
|---|---|
| `segments` | 4つのタイトル。上から順に再生 |
| `title` | `["1行目", "2行目"]` または `["1行だけ"]` |
| `ranks` | `[["◯日生まれ", "説明文"], ...]` を **1位→5位** の順に5つ |
| `bg` | 背景動画。`"bg/xxx.mp4"`、または途中で切り替える場合 `[["a.mp4", 0], ["b.mp4", 2.2]]`（数字はタイトル開始からの秒。3つ目に素材の開始位置秒を指定可） |
| `cta` | 1位表示後に出るクリーム色の帯。`lines` は3行、`{ }` で囲んだ部分が紫の強調。`colors` は `red` / `brown` |
| `bgm` | BGMファイル（省略時は無音トラック。アプリ側で音源を付ける想定） |
| `rain` | 斜めの雨線エフェクト（true/false） |

1つ目のタイトルは参考動画と同じく CTA なし（4.0秒）、2〜4つ目は CTA あり（各4.8秒）。

## 演出（参考動画の実測値）

- 5位→4位→3位→2位の順に約0.45秒間隔でタイプライター表示
- 1位は画面いっぱいの大きさからズームで着地（0.55秒）+ ゴールドの光
- 着地 0.35秒後に CTA 帯が左からワイプ → 文字がタイプ表示
- タイミングは `render.py` の `DEFAULT_TIMING`、または台本の `"timing"` で上書き可

## 背景動画

### 静止画から作る（おすすめ）

```bash
python3 make_photo_bg.py bg/photos/sea1.png --horizon 0.477 --water-end 0.80 -o bg/sea1.mp4
```

ゆっくりズーム・水面の揺れ・反射のキラキラ・星のまたたきを付けて6秒の動画にする。
`--horizon` は水平線の高さ（上から0〜1）、`--water-end` は波打ち際の高さ（これより下の砂浜は揺らさない）。

### プログラム生成

`make_sea_bg.py` が海の背景をプログラムで生成する（moon / sunset / rays / surface / deep）。
実写素材を使う場合は `bg/` に mp4 を置いて台本の `bg` に指定するだけ（縦横比は自動でクロップ）。
