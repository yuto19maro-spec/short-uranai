# 60秒 誕生日TOP5 台本の型

参考チャンネルの上位4本（450万・340万・290万・200万回）を、テロップ単位まで分解して作った型。
根拠データ（4本の完全書き起こしと実測値）は `REFERENCE_TOP4.md`。
台本はこの型どおりに `scripts60/<name>.json` に書く（書式は `README60.md`）。

---

## 1. テーマの決め方

**「〇〇な誕生日TOP5」**。〇〇は次のどちらか。誰でも自分ごとにできるテーマにする。

| 型 | 例（再生数） | 1位に向かって |
|---|---|---|
| 不安・ネガティブ | 苦難が多い（340万）、一生独身で終わる（290万）、孤独になりやすい（110万）、一生貧乏（91万） | 程度が強くなる |
| 特別感・選ばれた | 前世が人間ではない（450万）、天才が多い（200万）、前世が天使（160万）、紫のオーラ（130万）、心が綺麗（100万） | 特別さが強くなる |

- 修飾語「実は」「生まれつき」「一生」を付けて、生まれた時から決まっている感じを出す
- 伸びないテーマ: 年代を限定するもの（50代から〜）、他人の話（付き合ったら激変する人）、見た目（美男美女）
- 誕生日ランキング以外の型（〜のサイン5選、特徴5選）は伸びない（中央値2.4万回）

## 2. 全体の構成（60.00秒・テロップ約35枚）

| 秒（目安） | パート | テロップ枚数 | 役割 |
|---|---|---|---|
| 0〜2.6 | **タイトル** | 1 | サムネと同じ画面。3行 |
| 〜6.5 | **導入** | 2〜4 | テーマを言い換えて、自分ごとにさせる |
| 〜10 | **コメント誘導** | 2 | 「自分や身近な人の誕生日があったらコメント」 |
| 〜13.5 | **保存/フォロー誘導** | 2 | 「[この動画は2度と表示されないため]」で煽る |
| 〜16.7 | **ティーザー** | 1〜2 | 「特に最後は〜」で1位まで見させる |
| 〜26 | **第5位** | 4〜5 | 第N位 → 中身3枚 → 日付 |
| 〜34.5 | **第4位** | 4〜5 | 同上 |
| 〜43 | **第3位** | 4〜5 | 同上 |
| 〜52 | **第2位** | 4〜5 | 同上 |
| 〜60 | **第1位** | 4〜5 | 第1位 → 中身2〜3枚 → **「この誕生日は{コメント欄}」** |

導入〜ティーザーまでで約16〜17秒（全体の28%）。各順位は約8.5秒。

## 3. パートごとの型

### タイトル（3行）
```
1行目: 修飾語（実は／生まれつき／“一生”）や前置き      例: 実は前世が
2行目: {核心ワード} ← 必ず黄色・一番大きい              例: {人間ではない}
3行目: 誕生日TOP5
```
- 1行目と3行目は、片方を赤 `[ ]`、もう片方を白にする（参考4本はすべてこのどちらか）
- ナレーションは「〜誕生日トップファイブ」と読む（say で指定）

### 導入（次のどれか1つ）
| 型 | 書き方 | 実例 |
|---|---|---|
| 定義型 | この誕生日の人は / {〇〇}で → 「〇〇」の存在だった → 可能性があります | ① |
| 共感型 | {「なぜ私の〜なんだろう」} → と感じたことはありませんか？ → それはもしかしたら → {生まれた日}に理由があるかもしれません | ② |
| 宿命型 | 実は / {「〇〇」} → {宿命}を背負って生まれた人が存在します | ③ |
| 権威型 | 誕生日にはその人の{魂の設計図}が → 刻まれていると言われます → 今回は{“〇〇”}を宿して生まれてきた人に → 多い{誕生日TOP5}を紹介するので | ④ |

ネガティブなテーマ → 共感型・宿命型、特別感のテーマ → 定義型・権威型が合う。

### コメント誘導（2枚・固定文）
```
あなたや身近な人に / 同じ{誕生日}がいたら     （または: {あなた}や{友人}の / 誕生日が含まれていたら）
{コメント}で / 教えてください
```

### 保存/フォロー誘導（2枚・固定文）
```
[この動画は2度と / 表示されないため]          ← 2行とも赤
今のうちに / {保存}しておきましょう           （または: 今のうちに{フォロー}をして / 必ず最後まで見て下さい）
```

### ティーザー（1〜2枚）
| テーマ | 書き方 |
|---|---|
| ネガティブ | {特に最後は要注意！} |
| 特別感 | {特に最後は / 桁違いの〇〇！} |
| 共通（2枚） | 特に{1位}は / 今世でも → {“〇〇な使命”} / を背負っています |

### 各順位（第5位〜第2位）
```
第N位                                  ← 0.7秒。黄色なし
① 特徴: どんな性格・傾向か              例: 地に足がつかず → 現実より空想に生きる{感覚派}
② 深掘り: なぜそうなのか／その裏側      例: 前世は{空の存在・風の精霊}だった → 可能性が高い
③ 着地: 〜な魂／〜の持ち主／〜タイプ    （②と③はどちらか1枚にまとめてもよい）
この誕生日は / {〇日生まれ}             ← 「〇日生まれ」全体を黄色
```
- **誕生日は必ず最後**に出す。特徴を読ませて「自分っぽい」と思わせてから日付を見せる
- 中身は1順位あたり2〜4枚、合わせて5.5〜7秒
- ネガティブなテーマは「**〜しやすいが、〜**」で必ずポジティブに救う
  例: {苦労}が多く訪れるが → その分人として大きく{成長}するタイプ
- 特別感のテーマは「前世は〜だった{可能性が高い}／{とされる}」「〜タイプ」で言い切りすぎない
- 下の順位ほど身近で軽め、上の順位ほど強く・特別にする

### 第1位
```
第1位
① 最も強い特徴（短く言い切る）        例: {波乱}に次ぐ{波乱} / {人間の枠を超えた}
② 今世・運命につなげる                例: 今世でも / {“人に化けた何か”}として → 生きている可能性も
この誕生日は / {コメント欄}             ← 日付は言わない
```
- 1位の日付は動画内で言わず、**固定コメントで出す**（`pinned_comment`）。
  答えを知りたい人がコメント欄を開き、コメント数が伸びる。参考4本すべてがこの終わり方

## 4. テロップの書き方ルール

- 1枚 = 1〜2行、1行あたり **全角16文字以内**（それ以上は2行に分ける）
- 1枚あたり約1.7秒、ナレーション約6.8文字/秒 → **1枚の文字数は8〜14文字が目安**
- 文節の切れ目で改行する（「〜は / 〜」「〜を / 〜」「〜が / 〜」）
- 黄色 `{ }` は1枚に1〜2か所、名詞・属性（2〜8文字）だけ。日付は「〇日生まれ」全体、最後は「コメント欄」
- 造語やキーフレーズは “ ” か「 」で囲む（例: {“人間離れした使命”}、{「人間以外」}）
- 赤 `[ ]` は「この動画は2度と表示されないため」と、タイトルの1行だけ
- 文末: 「〜タイプ」「〜派」「〜な魂」「〜の持ち主」「〜しがち」「〜とされる」「〜可能性があります」「〜することも」

## 4.5 ナレーション（読み上げ）のルール

- **読み上げ文字数は合計400文字前後**（参考動画は約6.8文字/秒 × 約57秒 ≒ 390文字）。
  多いと話速が自動で上がりすぎる（例: 452文字 → 話速1.44）。`render60.py ... kana` で文字数を確認できる
- **各テロップは単独で意味が通る区切りにする**。助詞（を・が・に）で始まるテロップを作らない。
  ナレーションはカットごとに別々に合成するので、助詞始まりは抑揚が切れて不自然になる
  （参考動画の「であることも」のような文末の言い残しも避け、前のテロップにまとめる）
- `say`（読み）を最初から付けておく所:
  - 改行をまたいで単語がつながる所 → 改行位置に読点「、」を入れる（例: 争いを嫌い / 人の話 → 「争いを嫌い、人の話」。無いと「キライジンノ」と続けて読まれる）
  - 誤読しやすい語 → ひらがなにする（品のある → ひんのある、民に → たみに、一国 → いっこく）
  - 日付 → ひらがな（9日 → ここのか、24日 → にじゅうよっか、20日 → はつか など）
  - 「TOP5」→ トップファイブ
- **1つの文が複数のテロップにまたがるときは、2枚目以降に `"cont": true` を付ける**。
  その文はまとめて1回で読み上げ、テロップの切り替わり位置で音声を切り分けるので、抑揚が途切れず自然になる。
  付け忘れるとカットごとに文末の抑揚で読まれ、ぶつ切りで不自然に聞こえる
  - 付ける例: 「あなたや身近な人に〜いたら、」→「コメントで教えてください」、「〜表示されないため、」→「今のうちに保存〜」、
    「〜多いが、」→「最後は〜」、導入の「この誕生日の人は前世で」→「〜存在だった」→「可能性があります」
  - 付けない: 「第N位」、「この誕生日は〇日生まれ」、それだけで言い切っているテロップ
  - 続ける前のテロップが「〜たら」「〜ため」「〜が」で終わるときは、その `say` の末尾に「、」を付けて息継ぎを入れる
- 引用符 “ ” と「 」は、`say` を書かなければ自動で読みから外れる（入れたままだと不自然な間が入る）
- ローカルで書き出す前に `render60.py ... kana` で全カットのカナを確認し、誤読は `say` で直す

## 5. 日付の選び方

- **「〇日」だけ**（月は出さない）。1枠で視聴者の約1/31が当てはまる
- **5〜29日**から選び、5つとも違う日付にする（1桁と2桁を混ぜる）
- 1位の日付は台本の `pinned_comment` に書く

## 6. 画像の指示の型

| カット | 絵 |
|---|---|
| タイトル | テーマを象徴する人物（後ろ姿・横顔が多い）＋幻想的な光。サムネになる |
| 導入 | 宇宙・光・神秘的な人物（定義型・権威型）、悩む人の実写風（共感型） |
| CTA | 共通素材: ペンで書く手／手のひらのストップ／スマホを持つ手（`common/`） |
| 第N位 | 小さいシルエット・風景・後ろ姿など"間"の絵 |
| 特徴 | 内容を表す人物。表情・しぐさで感情を出す（悩む・微笑む・遠くを見る） |
| 日付 | 落ち着いた風景か象徴的な絵（水辺、光、木、空） |

- **子どもが泣いている・困っている構図、けが・血・暴力を連想させる構図は、Codex の安全フィルタで拒否されやすい**ので避ける
  （例: 泣いている子どもを助ける → 雨の中でベンチの年配の男性に傘を差し出す、に置き換えた）
- 1〜2テロップごとに画像を変える（1本で約28カット）。同じ画像で2テロップ続けるのはOK
- 全画像に共通スタイル: シネマティック、リアル寄りファンタジー、柔らかい光、縦長、**文字なし**
- ネガティブなテーマは暗め・青や紫、特別感のテーマは金色・白・虹色の光

## 7. 書いたあとのチェックリスト

- [ ] タイトル3行（2行目が黄色の核心ワード）
- [ ] 導入 → コメント誘導 → 保存/フォロー誘導（赤） → ティーザーの順になっている
- [ ] 5位〜2位は「第N位 → 中身 → この誕生日は{〇日生まれ}」
- [ ] 1位は「この誕生日は{コメント欄}」で終わり、`pinned_comment` に日付がある
- [ ] 日付は5〜29日で重複なし。読みにくい日付（9日・14日・20日・24日など）は say でひらがなにする
- [ ] テロップは約35枚、1行16文字以内
- [ ] 読み上げ文字数が約400文字（`kana` で確認）。助詞で始まるテロップが無い
- [ ] 改行で単語がつながる所・誤読しやすい語・日付に `say` を付けた
- [ ] 複数のテロップにまたがる文の2枚目以降に `"cont": true` を付けた
- [ ] `render60.py ... voice` で、ナレーション合計が60秒に収まる（超えたら中身を削る）

## 8. 投稿のしかた（参考チャンネル全38本の実測）

### タイトル（ハッシュタグはタイトルに入れる）
```
【フック‼️】テーマ誕生日TOP5🔮#shorts #スピリチュアル #開運 #誕生日占い #テーマのタグ1 #テーマのタグ2
```
- フック（強い順の目安。参考チャンネルの実績より）:
  1. **1位の中身を予告する**「最後は〇〇‼️」… 最後は桁違いの天才（200万）、最後は人生勝ち組（75万）。
     動画のティーザー・1位と同じ言葉にする（例: 最後は龍神そのもの）
  2. **煽る**「⚠️最後は要注意‼️」「コレガチでヤバい‼️」… 一生独身（290万）、前世が天使（160万）。ネガティブなテーマ向き
  3. **知らない人が多いことを強調する**「9割が知らない‼️」「99%が知らない‼️」… 最大450万だが8本の中央値は22万で当たり外れが大きい
- テーマの言葉も強める: 「一生」「誰にも」「実は」「生まれつき」を足し、核心ワードは “ ” で囲む（例: “一生”誰にも本音を言えない）
- ハッシュタグは **5〜6個**（100万回超えの8本は全部5〜6個）
  - 固定: `#shorts` `#スピリチュアル`（全38本）、`#開運`（34本）、`#誕生日占い`（誕生日ものの定番。付けた16本の再生数の中央値83万）
  - テーマに合わせて1〜2個: `#潜在意識` `#前世` `#魂` `#孤独` `#金運` `#恋愛` など
- **説明欄は空**（38本とも説明なし）。VOICEVOX を使う場合だけクレジット `VOICEVOX:冥鳴ひまり` を書く

### 投稿者コメント（最重要。投稿したらすぐ書いて固定する）
動画は「この誕生日はコメント欄」で終わるので、答えを投稿者コメントで出す。型は毎回同じ:
```
第1位は…〇日生まれ。
〇日生まれの人は、（1位の解説を2文。動画の内容を少し深掘り）

コメント欄に
「（開運ワード）」
と書き込むと、（〇〇が目覚める／引き寄せる などの効果）。
他の人のコメントにいいねをすると、（運気・ご縁・波動が上がる）。
```
- 開運ワードの実例: 「魂に感謝します」「私は光の存在です」「導きに感謝します」「優しさを受け取ります」「私は孤独を乗り越える力を持っている」「私は私の人生を生きます」
- 視聴者がこのワードと自分の誕生日をコメントするので、コメント数が大きく伸びる（上位動画はコメント700〜2,100件）。
  「他の人のコメントにいいね」でコメント欄の滞在とエンゲージメントも上がる
- 台本の `pinned_comment` にこの形で書いておく（書き出し時に out/<name>_pinned_comment.txt になる）

### Instagram・TikTok（YouTube の型を各媒体に合わせたもの）
- **キャプションにランキングの結果（何日が何位か）は書かない**（ユーザー指定）。答えは投稿者コメントだけで出す
- Instagram（リール）: タイトル → 導入の問いかけ2〜3行 → 「誕生日と開運ワードをコメント」→ シェアの呼びかけ →
  「2度と表示されないかもしれないので保存」→ フォローの呼びかけ → ハッシュタグ10個
  （#スピリチュアル #開運 #誕生日占い #誕生日 #占い ＋テーマ系）。投稿者コメントは YouTube と同じ文を固定
- TikTok: タイトル＋ひとこと「あなたの誕生日はあった？コメントで教えてね」＋ハッシュタグ5個（`#おすすめ` を含める）。
  **コメントは150文字まで**なので、投稿者コメントは「第1位は…〇日生まれ＋解説1文＋開運ワード」の短い版にする
- 絵文字はテーマに合わせる（例: 優しさ 🕊、王族 👑、前世・宇宙 🔮✨）
- 台本の `youtube_title` `youtube_description` `pinned_comment` `instagram_caption` `tiktok_caption` `tiktok_pinned_comment` に書く。
  `render60.py <台本> post`（または render）で out/<name>_post.txt にまとめて出る

- 序盤の「サイン5選」系は伸びず、誕生日TOP5に寄せてから100万回超えが連発した
