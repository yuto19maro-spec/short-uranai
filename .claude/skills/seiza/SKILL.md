# 星座ランキングTOP3（60秒）を作る

`render60.py` の60秒型に乗せる。テーマを決めて台本 `scripts60/seiza_<name>.json` を書き、push する。
動画の書き出し（画像・音声）はローカルPCで `uranai60` スキルの手順どおり行う。
見本の台本: `scripts60/seiza_sabishigari.json`（実は寂しがり屋な星座TOP3）。台本の書式・テロップのルールは `README60.md` と `scripts60/TEMPLATE.md` の4〜4.5節・6節・8節に従う。

## 1. テーマ

- 「〇〇な星座TOP3」。ユーザーがテーマを言わなければ、自分で1つ選んで提案して進める
- 型は2つ
  - 性格もの: 実は霊感が強い／頑張りすぎて疲れやすい／断るのが苦手で損をする／年を重ねるほど魅力が増す
  - 時期もの: 2026年◯月！金運の流れが変わる（今日以降の月にする）
- 修飾語「実は」「一生」「生まれつき」で自分ごとにする
- 3つとも別の星座。テーマに合う定番のイメージで選ぶ（霊感なら魚座・蟹座・蠍座、頑張りすぎなら乙女座・山羊座・天秤座など）。下の順位ほど軽く、1位が一番強く一番救われる内容にする
- 既存の `scripts60/seiza_*.json` と同じテーマ・同じ星座の組み合わせは避ける

## 2. 台本の型（元の読み上げ台本）

先にこの形で台本を書き、ユーザーにも見せる。

```
（テーマ）トップ3。
第3位は、〜な星座です。 なぜなら、〜からです。 例えば、〜。 （良い面を肯定する一文） その星座は〇〇座。
第2位は、…（同じ5文）
第1位は、…（同じ5文）
```

- 5文: ①特徴（星座名は伏せる）②「なぜなら〜からです」③「例えば〜」の日常のあるある ④弱点を強み・救いに言い換える ⑤「その星座は〇〇座」
- 時期ものは、②を星の動き（拡大の星・豊かさの星・縁を結ぶ星など）にし、④を「〜してみてください」などの行動を促す一言にする
- 短い文で言い切る。共感から肯定の流れにする

## 3. 60秒の台本(JSON)にする

見本 `seiza_sabishigari.json` と同じ並び（テロップ約25枚、読み上げ合計350〜400文字）:

| パート | テロップ |
|---|---|
| タイトル | `["実は", "{“核心ワード”}な", "[星座TOP3]"]`。say は「〜星座トップスリー」 |
| 導入 | 2枚。共感型（「一人で平気」と言いながら → 本当は〜な星座があります） |
| コメント誘導 | {あなた}や{友人}の / 星座が含まれていたら → {コメント}で / 教えてください |
| 保存誘導 | [この動画は2度と] / [表示されないため] → 今のうちに / {保存}しておきましょう |
| ティーザー | {特に最後は要注意！}（特別感のテーマは {特に最後は / 桁違いの〇〇！}） |
| 第3位〜第1位 | 「第N位」(say: 第三位) → ①特徴 → ②理由 → ③例えば → ④肯定 → 「その星座は / {〇〇座}」 |

- 1順位あたり中身3〜5枚。②③は短くするか1枚にまとめてよい（1行16文字以内）
- 星座名の say はひらがな（みずがめ座、しし座、さそり座、うお座、かに座、おとめ座、やぎ座、てんびん座、いて座、ふたご座、おうし座、おひつじ座）。前に「、」を入れる: `"その星座は、さそり座"`
- 1位も動画内で星座名を明かす（この型の特徴）。`pinned_comment` は「第1位は…〇〇座。」＋解説2文＋開運ワード＋いいねの呼びかけ（TEMPLATE.md 8節の形）
- 投稿文のハッシュタグは5個: `#shorts #スピリチュアル #開運 #星座占い` ＋テーマ1個。Instagram・TikTok も見本と同じ形で、`#誕生日占い` の代わりに `#星座占い`
- 画像: CTA は `common/` を使う。各順位の最後のカットは「その星座の星座線が光る夜空」の絵にする。プロンプトの書き方は見本と TEMPLATE.md 6節どおり

## 4. 確認して push

```bash
python3 -c "import json;json.load(open('scripts60/seiza_<name>.json'))"
python3 render60.py scripts60/seiza_<name>.json images              # 画像一覧が出るか
python3 render60.py scripts60/seiza_<name>.json render --silent     # 合計 60.00 秒になるか（フォントが無ければこの確認は省略）
```

台本だけコミットして push する。ユーザーには、台本の本文（2節の形）と、ローカルPCに貼る次のプロンプトを渡す:

```
git pull をしてから、scripts60/seiza_<name>.json の動画を uranai60 スキルの手順で作って。
画像はCodexで生成、ナレーションはVOICEVOXでお願い。
```
