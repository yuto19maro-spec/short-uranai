# 誕生日ランキング動画を作る

このリポジトリの `render.py` で、確定済みのフォーマットの縦型動画（1080x1920 / 30fps）を作る。
フォーマット（レイアウト・演出・タイミング・色）はユーザー確認済みで完成しているので、**変更しない**。
変えるのは台本の中身だけ。

## 1. 台本を受け取る

ユーザーから次の4セット分をもらう。メッセージに台本が無ければ、この形で送るよう頼む。

```
タイトル
1位 ◯日生まれ / 説明
2位 ◯日生まれ / 説明
3位 ◯日生まれ / 説明
4位 ◯日生まれ / 説明
5位 ◯日生まれ / 説明
```

「②動画目」などの表記は「1本の動画の2つ目のタイトル」の意味（4本別々の動画ではない）。

台本を受け取ったら軽くチェックして、気になる点があれば伝える（直すのはユーザーが望んだときだけ）:
- 4タイトル全体で同じ誕生日が重複していないか
- 1〜31日の範囲か
- 誤字

## 2. 準備

```bash
./setup.sh      # フォント・OpenCV・背景動画 (bg/sea1〜4.mp4) を足りない分だけ用意。初回は1〜2分
```

## 3. 台本ファイルを書く

`scripts/<テーマの英語名>.json` を作る。**`scripts/fukuen.json` をそのまま雛形にする**（構造・背景・CTA の書き方はこれが正）。

- `ranks` は **1位→5位の順**に `["◯日生まれ", "説明"]`
- `title` は2行に分ける。参考動画にならい、文節の切れ目で区切り、2行目を「〜誕生日」「〜人」で終える。
  例: `["相手から", "連絡が来る誕生日"]`、`["復縁が近い", "誕生日"]`。長すぎる行は自動で縮小される
- 背景: 1つ目 `bg/sea1.mp4`、2つ目 `bg/sea2.mp4`、3つ目 `bg/sea3.mp4`、4つ目 `bg/sea4.mp4`
- 1つ目のタイトルには `cta` を付けない（参考動画どおり）
- 2〜4つ目の `cta`（カットイン）はユーザー指定の次の文言をデフォルトで使う。ユーザーが別の文言をくれたらそれに差し替える:
  - 2つ目（いいね誘導）: `["この恋の流れをいい方向にするために", "{『いいね』}してね"]` / colors `["red", "brown"]`
  - 3つ目（フォロー誘導）: `["復縁の流れを見逃さないために", "これからも必要なメッセージを届けます", "今のうちに{『フォロー』}してね"]` / colors `["red", "brown", "brown"]`
  - 4つ目（コメント誘導）: `["あなたとお相手のご縁をつなぐために", "①コメントに{『誕生日』}を書く", "②この動画を{友達に共有}してね"]` / colors `["red", "brown", "brown"]`
  - テーマが復縁以外のときは、1行目の言い回しをテーマに合わせて調整してよいか一言聞く
  - `{ }` で囲んだ部分が紫の強調文字。CTA は2行か3行

## 4. 確認して書き出す

```bash
# 静止画で確認 (各タイトルの CTA が出た状態)
python3 render.py scripts/<name>.json --preview 3.8
python3 render.py scripts/<name>.json --preview 8.6
python3 render.py scripts/<name>.json --preview 13.4
python3 render.py scripts/<name>.json --preview 18.4
# 本番
python3 render.py scripts/<name>.json -o out/<name>.mp4
```

プレビュー画像を見て、文字のはみ出し・重なりがないか確認してから本番を書き出す。
書き出した mp4 は SendUserFile でユーザーに送る（BGM なし。音源はアプリ側で付ける運用）。

## 5. 保存

台本 JSON をコミットして push する（`out/` の動画はコミットしない）。
空リポジトリ由来の不具合で push が失敗する場合は `git -c push.negotiate=false push -u origin <branch>` を使う。
